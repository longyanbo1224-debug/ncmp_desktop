# ncmp v1.2.3

执行时曲目表的加载顺序修正、关于页下载入口改为直达国内镜像，以及托盘与打包相关的一批修复。

## 双端共同

### 改进

- **曲目表一次摆出**：执行时先取好基础与额外两份清单，合并成一次刷新交给界面，
  不再"先闪 5 行、再跳成 15 行"

### 修复

- **桌面端曲目表一首一首冒出来**：把合并后的列表传给了按字典取值的回调，异常被吞掉，
  导致一行都没有预置。现在接口按"列表"约定，并补了回归测试

## 桌面端

### 改进

- **计数口径改为曲目行数**：页头「今日 N/M」与右栏「已完成 N/M」的分母取曲目表行数
  （基础 + 额外，含待评），不再出现「显示 0/5、列表里却有 19 行」的对不上

### 修复

- **托盘「退出」后进程没退**：从托盘菜单触发时正处在菜单的嵌套事件循环里，
  `quit()` 只退出了那一层，主循环还在跑（表现为任务栏图标仍在、点一下秒开）。
  改为延迟到主事件循环再退出
- **托盘图标没显示时点叉窗口会消失**：改为弹确认框「退出程序 / 最小化到任务栏」；
  启动 1.5 秒后若托盘图标仍不可见，会重新挂载一次
- **打包版启动报 `No module named 'app.ui.main_window'`**：源码里一处手误导致语法错误，
  PyInstaller 把该模块记为 invalid 直接丢弃。已修复，并新增"全量编译自检"测试防复发
- **打包漏资源**：下拉箭头图片没打进包、样式资源不会自动生成；已补进打包脚本并加入产物校验

### 关于页

- 「更新与下载」改为**独立一行**（此前塞在版本号那行的小字里），并直达国内镜像的
  Releases 取链页，少一步手动粘贴仓库地址
- 行顺序与手机端对齐：GitHub / 更新与下载 → 致谢 → 作者 → 核心依赖 → 许可

## 手机端

### 关于页

- 「更新与下载」同样改为直达国内镜像的取链页
- 移除页内的「国内下载」分步指引（入口已经一步直达，不再需要）

## 说明

- 额外任务接口是**分批返回**的：先给一批，评到中途再请求才会给下一批。
  曲目表会随批次增长（例如 15 → 20），这是接口行为，不是丢歌

## 升级

- 桌面端：退出旧版本，解压并覆盖整个 `ncmp desktop` 文件夹（`_internal` 也一起更新）
- 手机端：安装 `ncmp-mobile.apk` 覆盖安装，登录态与配置保留

安装包：`ncmp.desktop.zip` / `ncmp-mobile.apk`
