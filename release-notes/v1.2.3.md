# ncmp v1.2.3

记录页的「合伙人」这块补齐：除了本期积分，现在还会显示本周积分，并按积分换算出称号。

## 双端共同

### 新增

- **称号换算**：按本期积分显示当前称号与距下一档还差多少分，并列出阈值表

  | 积分 | 称号 |
  |---|---|
  | 320 | 高级音乐合伙人（可维持身份） |
  | 400 | 资深音乐合伙人 |
  | 480 | 首席音乐合伙人 |

  低于 320 显示「未达保级线」；分数拿不到时整块不显示（不填 0）
- **本周积分**：按接口实测字段 `currentWeekIntegral` 读取

### 说明

- 接口实际只返回 `integral`（本期积分）与 `currentWeekIntegral`（本周积分）；
  云贝余额 / VIP 等级 / 成长总值在这份返回里没有，界面继续"没数据就不显示"
- 平台还返回一个 `title` 字段（如 `CHIEF`），但含义与本地阈值规则对不上
  （454 分时它给的是 CHIEF，而规则里 480 才首席），因此**不显示**，避免两种口径打架

## 桌面端

### 改进

- 查询成功时把**原始字段名**打到 debug 日志，便于以后接口改字段名时快速定位

### 升级

- 退出旧版本，解压并覆盖整个 `ncmp desktop` 文件夹（`_internal` 也一起更新）
- 配置、登录态、记录与积分缓存都在用户目录，覆盖安装不会丢

安装包：`ncmp.desktop.zip`

## 手机端

### 修复

- **合伙人积分不显示**：请求改用 `mp.music.163.com` 作为 Referer；
  `data` 不是对象时改为摊平整份响应再找字段
- **失败时没有线索**：请求异常 / `code != 200` / 未识别到字段，都会写一行到「运行详情」

### 升级

安装 `ncmp-mobile.apk` 覆盖安装即可，登录态与配置保留。

安装包：`ncmp-mobile.apk`
