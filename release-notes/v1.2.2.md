# ncmp v1.2.2

曲目表的显示与收尾、记录页的可读性、手机端深色主题，以及设置页按桌面窗口重做的一轮（扁平化、下拉统一、批注长度三档）。

## 双端共同

### 改进

- **一开始就能看到今天全部曲目**：执行时先拉基础任务与额外任务两份清单，
  不再"先 5 首、评完才冒出额外 15 首"
- **跨设备评过的歌补进本机记录**：服务端标为「已评过」的曲目会写进本地记录
  （分数用服务端的；本机没写过批注就留空），手机评过的歌在电脑「记录」页也能看到，反之亦然
- **批注三档长度真正生效**：简短（40 字以内，只留判断）/ 标准（80 字以内，带开场与收尾）/
  详细（60-120 字，多写一句判断）。三档改变的是句式，不只是截断阈值
- **三段独立哈希**：开场、判断、收尾各用一份哈希取词，不再"每首开头都一样"；
  同一次运行内不重复使用同一句开头（实测 20 首出现 16 种开头）
- 去掉「朋友提过一嘴，今天才点开」这类暗示"别人已经听过"的开头
- 接外部 LLM 时，提示词与 `max_tokens` 跟随所选长度档

### 修复

- **被服务端拒绝的作品不再挂着「待评」**：任务结束时把没轮到的行统一标为「跳过」
  （今天额度用完时最明显：以前会一直停在待评，看着像程序没跑完）

## 桌面端

### 新增

- **记录页积分刷新**：「合伙人」右侧新增「刷新」，走后台线程查询，查到即更新缓存与界面
- **最近曲目可折叠**：默认收起，标题带条数；展开后是一块独立的可滚动区域

### 改进

- **控件扁平化**：按钮、下拉、步骤树、日志面板去掉 1px 描边，改用浅灰填充分层；
  次按钮（测试通知 / 验证 Cookie / 导入 / 导出 / 打开日志文件夹）保留一条细边，避免和禁用态混淆
- **设置页分页签各自滚动**：短页签不再出现滚动条，长页签（自动化）只在自己的区域内滚动；
  账号 / 任务 / 通知 / 通用四页一屏放得下
- **下拉统一**：箭头补齐（此前样式表接管后默认箭头消失）、固定向下展开、
  短列表一次全展开、长列表最多 16 行、宽度按最长选项自适应
- **时间与延迟改成下拉**：触发时间 / 补跑截止拆成「时 + 分」两个下拉；
  本地随机延迟、云端 cron 时间同样改为下拉（数字框的上下小箭头已去掉，直接键入更快）
- **等待时间并排一行**：最小 / 最大放在同一行，便于对照
- **对话框自绘**：替换系统风格的 `QMessageBox`，标题 15px、正文 13px、按钮靠右、图标按语义着色
- **键盘焦点收成 1px**：点完按钮不再挂着 2px 粗框（红底上尤其像贴了黑边）
- **输入框统一列宽**：所有字段同宽；带按钮的行（明文密码 + MD5）把按钮移进输入框内

### 修复

- **跑完任务后看不到步骤与日志**：不再自动收起「运行详情」，跑完仍保持展开
- **通知气泡透明、像没加载完**：半透明窗口下样式表背景画不出来，改为自绘圆角面板；
  淡入动画被打断时也会把不透明度拉满
- **通知气泡是直角方块**：无边框窗口补上半透明背景，圆角按样式表裁切
- **展开最近曲目会挤压打卡格子图**：整页改为可滚动，图例不再被挡
- **任务页最后一个下拉贴着底边**：合并等待时间两行、压短说明、底部留白，全部页签一屏放得下

### 变更

- 关于页作者署名改为 **Loong**

## 手机端

### 新增

- **「合伙人」刷新**：手动查一次积分与称号；阈值表改为小号灰字，不再抢视觉重心

### 改进

- **「批注长度」改为三档 chip**（简短 / 标准 / 详细），与桌面端一致；
  生成规则同步（简短只留判断、详细多写一句判断、分段哈希取词）

### 修复

- **点「保存设置」没有任何反馈**：此前只往折叠的「运行详情」写一行日志。
  现在保存后会在按钮下方显示 2.5 秒提示（开后定时时会回读「每天 HH:mm 执行」）
- **深色主题真正生效**：此前只有深色配色定义，界面仍用固定浅色值，深色下正文发黑；
  现在配色跟随系统深浅色（取值与桌面端一致）
- 电平表未点亮的格子跟随主题

## 升级

- 桌面端：退出旧版本，解压并覆盖整个 `ncmp desktop` 文件夹（`_internal` 也一起更新）
- 手机端：安装 `ncmp-mobile.apk` 覆盖安装，登录态与配置保留

安装包：`ncmp.desktop.zip` / `ncmp-mobile.apk`
