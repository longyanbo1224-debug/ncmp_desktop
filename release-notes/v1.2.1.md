# ncmp v1.2.1

今晚（2026-10-29）的全部更新合并进这一版：批注语料与句式、曲目表在"已评完"时的显示、
打卡图的平板/横屏适配、结果不明不重投、合伙人积分与称号、日志脱敏。

## 双端共同

### 新增

- **批注语料扩容**：开场 10 → **20** 句，判断每档 6 → **12** 句（克制）/ 10（热络）/ 8（简短），
  收尾 8 → **14** 句；部分收尾句带歌名（`{name}`，拿不到歌名时自动跳过）
- **四种句式排法**：三段全用 / 省掉收尾 / 省掉开场 / 只留判断，按同一颗种子轮换。
  同一首歌、同一个分数仍然**永远生成同一句**，只是看起来不再像同一个模子
- **合伙人积分**：任务结束后查询一次，记录页有数据才显示
- **称号换算**：按本期积分显示当前称号与距下一档还差多少，并列出阈值表

  | 积分 | 称号 |
  |---|---|
  | 320 | 高级音乐合伙人（可维持身份） |
  | 400 | 资深音乐合伙人 |
  | 480 | 首席音乐合伙人 |

  低于 320 显示「未达保级线」；分数拿不到时整块不显示（不填 0 假装有收益）
- **本周积分**：按接口实测字段 `currentWeekIntegral` 读取
- **结果不明不重投**：评分请求超时 / 断连时，只**查一次**服务端确认这首是否已评上，
  确认到就按成功处理，**绝不重新提交**——超时不代表服务端没收到，重投就是重复评分
- **日志脱敏**：LLM key、Cookie、csrf、Bearer token 在写日志处统一遮蔽，长行截断到 400 字

### 修复

- **本地计数与线上不一致**：服务端返回「资源状态异常」时原来被当成评分成功计入，
  现在只有服务端真的记下评分才算成功；完成文案也只数"已评完"的行
- **说不清缺的是哪首**：被服务端拒绝的作品会在结束时**点名**，并说明"重复执行也不会成功"，
  不用再靠反复点执行去猜
- **简短语气出现「。。」双句号**：判断句自带句号，拼接时又补了一个
- **简短语气偶尔变长**：应只有一句、不超过 16 字，之前会带上开场白

### 说明

- 接口实际只返回 `integral`（本期积分）与 `currentWeekIntegral`（本周积分）；
  云贝余额 / VIP 等级 / 成长总值在这份返回里没有，界面继续"没数据就不显示"
- 平台还返回一个 `title` 字段（如 `CHIEF`），含义与本地阈值规则对不上
  （454 分时它给的是 CHIEF，而规则里 480 才首席），因此**不显示**，避免两种口径打架

## 桌面端

### 改进

- **向手机端看齐**：控件圆角 8px、面板 10px，按钮留白加大一档；曲目表与今日页右栏**去掉白卡片**
  （行间只用细线，右栏改成一条竖线分隔）；记录页三个数从卡片改为纯文字块
- **运行日志可见**：任务一开始自动展开「运行详情」，日志边跑边看；顺利跑完自动收起，
  失败 / 取消保持展开
- 查询积分成功时把**原始字段名**打到 debug 日志，便于以后接口改字段名时快速定位

### 修复

- **已评完再点「立即执行」只能看到 5 首**：额外任务里**已评过**的那些现在也会列出来（带服务端分数）
- **托盘右键菜单没有圆角**：QMenu 是独立弹出窗口，默认没有半透明背景，样式表的圆角会被方形窗口裁掉
- **窗口默认出现在左上角**：启动时按主屏可用区域居中（并按屏幕大小收敛尺寸，避免高 DPI 下顶出屏幕）
- **本地计数比线上多一首**：服务端返回「资源状态异常」时，原来被当成评分成功计入。
  现在只有服务端真的记下评分才算成功，跳过的会交给补跑轮次再核对；
  完成文案也改成只数"已评完"的行，不再把"待评"行算进成绩

### 升级

- 退出旧版本，解压并覆盖整个 `ncmp desktop` 文件夹（`_internal` 也一起更新）
- 配置、登录态、记录与积分缓存都在用户目录，覆盖安装不会丢

安装包：`ncmp.desktop.zip`

## 手机端

### 新增

- **记录页三个数**：连续天数 / 累计曲目 / 累计批注（宋体大数字，位置与桌面端一致）
- **分组骨架统一**：15sp 半粗小标题 + 1px 细线，与桌面端同一套

### 修复

- **已评完再点执行时曲目表一首都没有**：每日任务与额外任务的整份清单（含已评过的）都会摆进曲目表
- **「记录」页最近评过的曲子不能折叠**：默认收起，点标题展开
- **打卡图浮层底色是黑色的**：改用页面底色，并去掉「点空白处退出」的提示文字（点任意处退出）
- **打卡图不适配平板宽度**：格子尺寸改为跟随可用宽度，不再有 6dp 上限
- **平板 / 横屏点开打卡图反而变小**：浮层只在**竖屏**时旋转 90° 沿长边铺开；横屏直接用整屏宽度
- **合伙人积分不显示**：请求改用 `mp.music.163.com` 作为 Referer；`data` 不是对象时
  改为摊平整份响应再找字段；请求异常 / `code != 200` / 未识别到字段都会写一行到「运行详情」

### 升级

安装 `ncmp-mobile.apk` 覆盖安装即可，登录态与配置保留。

安装包：`ncmp-mobile.apk`

  无双句号、简短必须 ≤16 字、日志脱敏、积分解析、称号阈值、真实返回结构、
