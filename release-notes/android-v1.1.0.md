# ncmp mobile v1.1.0

在 v1.0.0 基础上，新增**定时执行**与**打卡记录**，并按桌面端设计语言重做了整个界面。

## 新增

- **定时执行**：每天 `HH:mm` 自动执行。使用系统精确闹钟，开机 / 重开 App 自动重排；到点由前台服务在后台执行
- **打卡记录**：底部「记录」页查看每次执行结果（日期 / 时间 / 成功失败 / 取消），保留最近 60 条
- **后台执行增强**：任务改由前台服务执行，配合 WakeLock + WiFi 锁，切后台 / 锁屏继续跑
- **后台保活设置**：参数页一键请求「忽略电池优化」

## 改进

- **界面重构**：按桌面端设计语言重做——网易云品牌红 + 分段电平表作视觉主角 + 衬线大标题 + 细线分层，去掉卡片堆叠的模板感
- **网页登录更顺手**：保持原始大小（按钮不缩小），自动滚动定位到登录区域，支持**双指捏合缩放**
- **额度识别**：遇到「今日没有更多可评定歌曲」立即停止，不再逐个空转浪费时间
- **退出登录保留配置**：只清除登录态，评分策略 / 等待时间 / 定时设置全部保留
- **昵称修复**：启动时从接口拉取真实昵称，不再显示「网易云用户」占位

## 修复

- 修正 **WeAPI 二次加密**（第二轮应加密 base64 字符串而非原始密文字节）——这是评分接口在手机端返回空响应、评分失败的根因
- 修复状态栏（刘海）遮挡用户名 / 退出按钮
- 修复参数展开后被裁切、无法滚动的问题
- 修复定时任务因缺少「精确闹钟」权限被系统拦截的问题

## 说明

- 定时执行需要授予「**闹钟和提醒**」权限；MIUI / HyperOS 还需「自启动」+「省电无限制」+ 后台锁定
- 非官方第三方程序，仅供个人学习、研究和技术交流，使用风险自负

## 安装

下载 `ncmp-mobile.apk`，覆盖安装即可（登录态与配置会保留）。
