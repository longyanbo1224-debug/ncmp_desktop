# ncmp mobile v1.1.2

修正上一版对「今日没有更多可评定歌曲」的误判。这条 405 表示今天能评的歌已经评完，不是额度用完。

## 修复

- 收到这条提示时，日志改为「今日已没有更多可评定歌曲，额外任务今日已全部完成」
- 不再提示「检查后仍有 15 个额外评分任务未完成」，也不会再触发补跑
- 本次额外评分为 0 首时，历史记录写成「额外任务今日已全部完成」，不再显示「额外 0 首」

## 升级

- 安装 `ncmp-mobile.apk` 覆盖安装即可，登录态和配置保留

安装包：`ncmp-mobile.apk`
