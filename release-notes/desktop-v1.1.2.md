# ncmp desktop v1.1.2

修正上一版对「今日没有更多可评定歌曲」的误判。这条 405 表示今天能评的歌已经评完，不是额度异常。

## 修复

- 收到这条提示时，日志改为「今日已没有更多可评定歌曲，额外任务今日已全部完成」
- 不再提示「检查后仍有 15 个额外评分任务未完成」，也不会再触发补跑
- 基础阶段遇到同一提示时，文案改为「今日已没有更多可评定歌曲，停止基础评分」

## 升级

- 退出旧版本，解压并覆盖整个 `ncmp desktop` 文件夹（不要只替换 exe，`_internal` 也一起更新）
- 配置、登录态和历史记录都在用户目录，覆盖安装不会丢

安装包：`ncmp.desktop.zip`
