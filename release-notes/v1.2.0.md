# ncmp v1.2.0

评分这一环重做：不再只是"机器跑完了"，而是**今天评了哪几首、每首几分、留下了什么话**。
双端都参考了开源项目 [Grails125/ncmm](https://github.com/Grails125/ncmm)（音乐合伙人评分 / 推荐歌曲笔记与乐评的自动化工具），
取了它"把评分当成留下一条批注来做"的思路，没有取它的多账号并行与 WebUI/Docker 部署形态。

## 桌面端

### 新增

- **批注（乐评文案）**：评分时同时提交一句批注，不再把评论字段留空。
  本地模板库生成，不联网、不调用 AI、不内置任何 key；同一首歌每次生成同一句（种子取作品 id）
- **三套语气**：克制（默认）/ 热络 / 简短。两条底线：不编造听觉细节（程序没听过这首歌）、不喊口号
- **可选接自己的 LLM**：填 OpenAI 兼容的 endpoint + 模型 + key 后生效，失败自动回落本地模板
- **记录页**：每天评了哪几首、每首几分、留下什么话；累计曲目 / 累计批注 / 连续天数
- **口味曲线**：你自己的 5/4/3/2/1 档分布与占比
- **今日内页导出**：今天的曲目 + 批注存成 Markdown
- **策略预演**：不提交、不改配置，用今天真实歌单算出四种评分策略各会给出什么
- **等待倒计时**：随机等待显示成「再等 N 秒，避免触发风控」
- **深色主题**：跟随系统深浅色（启动时读取，运行中不切换）

### 改进

- **今日页主视角换成曲目表**：序号 / 歌名（宋体）/ 档位 `4⁄5` / 状态 / 批注（宋体引文）
- **步骤树与日志降级**为默认收起的「运行详情」，只在失败时自动展开
- 电平表保留，收成页头下方一条细带
- 左导航「任务」→「今日」，新增「记录」
- **设置页拆成页签**：账号 / 任务 / 通知 / 自动化 / 通用，一个主题一页，不用再一路滚到底

### 修复

- **今日页启动时读回当天记录**：之前今天跑过之后再开程序，会显示「今天还没有排到曲子」
- **已评完再点执行时曲目表只有 5 首**：额外任务里**已评过**的那些也会列出来（带服务端分数），不再只显示基础任务
- **记录打卡图的图例不再被下方标题盖住**（上一版把格子图的固定高度压小了）

### 升级

- 退出旧版本，解压并覆盖整个 `ncmp desktop` 文件夹（不要只替换 exe，`_internal` 也一起更新）
- 配置、登录态、历史记录与新的记录文件 `track_log.json` 都在用户目录，覆盖安装不会丢
- 批注默认**开启**：第一次跑就会把批注发到账号上。想先只评分不写批注，到设置页关闭「评分时同时提交批注」

安装包：`ncmp.desktop.zip`

## 手机端

### 新增

- **批注（乐评文案）**：与桌面端同一套语料、同一条规则，评分时把批注一并提交
- **三套语气**：克制（默认）/ 热络 / 简短，可切换；字数上限默认 80 字
- **曲目表**：今天评了哪几首、每首几分、留下了什么批注，一条一条列出来，可折叠
- 曲目行会显示 `待评 / 评分中 / 已提交 / 跳过 / 失败` 五种状态，不只是"当前这一首"

### 改进

- **页头改成日期 + 一句状态陈述**：`10月28日 周二` ／ `今日 3/5 · 已提交 3 条批注`，大标题「今日评分」退场
- **打卡图可横屏看图**：点一下格子图，图本身转 90° 铺满长边、格子放大（不动整个应用的屏幕方向），点任意处退出
- **「记录」页补齐**：按曲目记账（哪天/哪首/几分/写了什么）+ 口味曲线（5→1 档分布）+ 最近评过的曲子，和桌面端一致
- **顶栏显示版本号**：`ncmp · v1.2.0`

### 修复

- **执行结束时收尾曲目表**：之前今天已经评过歌、点执行只跑一首就结束，第一首会一直显示「评分中」、下面全挂着「待评」；
  现在结束时未跑完的行会记为「跳过」（失败时记为「失败」）
- **退出登录后「Cookie」页仍能看到上次的 MUSIC_U / __csrf**：之前只有走网页登录流程才会填这两个输入框
- **已评完再点执行时曲目表是空的**：每日任务与额外任务的整份清单（含已评过的）都会摆进曲目表，并带上服务端分数
- **「记录」页最近曲目可折叠**：默认收起，点标题展开

### 尚未完成

- 「记录」页还是只有打卡图，没有对齐桌面记录的累计 / 口味曲线 / 最近曲目
- 运行日志收进「运行详情」折叠区（失败自动展开）
- 手机端不接外部 LLM（选了 llm 也走本地模板，日志里会说明）
- 单曲留白（这一首不写批注）只在桌面端有
- 多账号切换：双端都还没有（v1.3 计划）

### 升级

安装 `ncmp-mobile.apk` 覆盖安装即可，登录态和配置保留。

安装包：`ncmp-mobile.apk`

## 双端共同

- **结果不明不重投**：评分请求超时/断连时，只**查一次**服务端确认这首是否已评上（确认到就按成功处理），**绝不重新提交**——超时不代表服务端没收到，重投就是重复评分
- **合伙人积分/等级**：任务结束后查一次云贝余额 / VIP 等级 / 成长总值 / 本期·本周积分，记录页有数据才显示，拿不到就整块隐藏（不填 0 假装有收益）
- **日志脱敏**：LLM key、Cookie、csrf、Bearer token 在写日志的地方统一遮蔽，长行截断到 400 字——日志会落盘 7 天，凭据不能进去
- 评分判定抽成纯函数（桌面端 `core/scoring.py`），策略预演与测试共用同一份规则
- 设计规范落到 `docs/DESIGN.md`：配色、排版、曲目行组件、双端线框、文案用词表
- 桌面端 45 个单测（含页面构造冒烟、记录读写、批注生成、策略预演、评分区间不变量、日志脱敏、积分解析）
- 新增 GitHub Actions：打 `v*` tag 自动编译桌面端与手机端并发布 Release
