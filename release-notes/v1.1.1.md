# ncmp v1.1.1（桌面端 + 手机端）

本次桌面端与手机端同步发布，重点是**任务跑完整**和**记录看得懂**。

## 共同改进

- **额外任务补跑**：单首评分失败会被跳过，整轮结束后重新拉取服务端任务列表并补跑一轮。不会再出现「15 条只评了 12 首」却直接结束的情况
- **失败策略统一**：额度用完按正常结束处理，不判失败、不发失败通知；单首遇到「频繁」最多试 3 次后放弃，避免无限重试
- **进度条**：两个评分阶段按条目数分配全局进度，基础 5 首跑完不会先顶到 100%，额外任务也不会从 0 重新开始
- **打卡图配色**：绿=成功、红=失败、灰=没跑，桌面端与手机端一致

## 桌面端（Windows）

- **单实例唤醒**：已经启动（包括最小化到托盘）时再次双击图标，直接把已有窗口拉到前台，不再弹「已在运行」
- **限流重试上限**：单首最多尝试 3 次，定时任务不会因为持续限流永远结束不了
- **额度用完处理**：基础阶段额度用完不再判整次任务失败，会继续尝试额外任务
- **电平表**：只前进不后退，补跑时目标数变化不会让进度条倒退
- **打包**：`build.bat` 只清理自己的 `dist\ncmp desktop`，不会删除 Android 的 APK

## 手机端（Android）

- **打卡记录页重做**：一年格子图 + 图例 + 连续/累计天数；下面是按天合并的执行情况——同一天多次执行收在同一条，点开看每次的时间、状态和失败原因
- **进度条与桌面端一致**：跨阶段全局进度，显示百分比；取消时停在当前进度并变灰
- **执行结果更具体**：记录里写明基础 / 额外各评分了多少首
- **记录自动刷新**：任务结束、切到「记录」页都会读到最新结果

## 升级

- 桌面端：退出旧版本，解压覆盖整个 `ncmp desktop` 文件夹（不要只替换 exe）
- 手机端：安装 `ncmp-mobile.apk` 覆盖安装，登录态与配置保留
