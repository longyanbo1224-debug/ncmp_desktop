# 手机端 v1.2.0 —— 曲目表 + 批注

与桌面端 v1.2.0 同一套规则，方向同样参考了 [Grails125/ncmm](https://github.com/Grails125/ncmm)。

## 新增

- **批注（乐评文案）**：评分时把 `comment` 字段填上，不再留空。
  语料与桌面端逐句一致（`data/Notes.kt`），本地生成、不联网；同一首歌每次生成同一句。
- **三套语气**：克制（默认）/ 热络 / 简短，可在「任务参数」里切换。
  两条底线不变：不编造听觉细节、不喊口号。
- **字数上限**：默认 80 字，超出先丢收尾句再截断。
- **曲目表**：今天评了哪几首、每首几分、留下了什么批注，一条一条列出来。

## 改版

- 「任务」页页头改成 **日期（宋体 22）+ 一句状态陈述**（`今日 3/5 · 已提交 3 条批注`），
  大标题「今日评分」退场。
- 曲目表取代"只看当前这一首"的展示：序号 / 歌名 / 档位 `4⁄5` / 状态点 / 批注（宋体引文）。
  行与行之间只有一条细线，不做卡片。
