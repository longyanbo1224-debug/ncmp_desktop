# ncmp desktop v1.1.1

本次重点修「任务跑完整」和「桌面图标」。

## 改进

- **额外任务补跑**：单首评分失败会被跳过，整轮结束后自动重新核对服务端任务列表并补跑一轮。不会再出现「15 条只评了 12 首」却直接结束
- **失败处理更合理**：服务端提示「今日没有更多可评定歌曲」时按正常结束处理，不判整次任务失败，也不再发失败通知；单首遇到「频繁」最多试 3 次后放弃，避免无限重试
- **进度条只前进不后退**：补跑时任务目标数变化不会让进度倒退
- **重复启动更顺手**：已经启动（包括最小化到托盘）时再次双击图标，直接把已有窗口拉到前台，不再弹「已在运行」

## 修复

- **图标统一**：窗口、系统托盘和应用内通知改用与新 exe / 桌面快捷方式同一份图标，不再显示旧音符

## 升级

- 退出旧版本，解压并覆盖整个 `ncmp desktop` 文件夹（不要只替换 exe，`_internal` 也一起更新）
- 配置、登录态和历史记录都在用户目录，覆盖安装不会丢
- 如果更新后托盘图标仍是旧的，重启一次资源管理器（任务管理器 → Windows 资源管理器 → 重新启动）或重启电脑；Windows 的托盘图标缓存不会随 exe 替换自动刷新

安装包：`ncmp.desktop.zip`
