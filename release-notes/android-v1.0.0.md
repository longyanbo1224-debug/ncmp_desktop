# ncmp mobile v1.0.0

首个 Android 版本。把网易云音乐「音乐合伙人」每日评分任务搬到手机上，手动一键执行。

## 功能

- **官方网页登录**：内嵌 WebView 直连网易官方登录页，支持手机号 / 验证码 / 扫码等官方方式；另支持直接粘贴 Cookie 绕开风控
- **手动执行任务**：验证用户 → 拉取每日任务 → 评分基础任务 → 额外评分任务
- **实时进度与日志**：分段电平表进度 + 逐首评分日志，日志支持一键复制
- **失败原因分类**：Cookie 失效 / 风控拦截 / 网络异常 / 接口错误 / 未知，并给出下一步建议
- **后台执行**：任务在**前台服务**中运行，切后台 / 锁屏不中断（常驻通知）
- **本地加密存储**：Cookie 存 Android Keystore 加密的 SharedPreferences

## 说明

- 接口与加密逻辑与桌面端 `core/` 完全一致
- 首次启动需允许**通知权限**（前台服务常驻通知需要）
- 非官方第三方程序，仅供个人学习、研究和技术交流，使用风险自负

## 安装

下载 `ncmp-mobile.apk`，在手机上允许「安装未知来源应用」后安装。
