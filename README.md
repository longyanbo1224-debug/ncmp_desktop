## 这是什么

ncmp 可以帮你自动完成网易云音乐「音乐合伙人」的每日评分任务：

- 每天自动评 **20 首**（基础任务 5 首 + 额外任务最多 15 首）
- 评分时顺手留下一句乐评批注
- 记录今天评了哪些歌、每首几分、写了什么，并画出你的口味曲线
- 桌面端、手机端都能用；电脑关机时还可以交给 GitHub Actions 云端执行

它想解决的是「今天跑了吗？成功了吗？评了哪些歌？」——打开就能看到，不用翻日志。

> 仓库 fork 自上游 [ACAne0320/ncmp](https://github.com/ACAne0320/ncmp)。

## 功能一览

### 评分与任务

- **每天 20 首**：基础 5 首 + 额外最多 15 首，一次全部摆出来，不会先显示 5 首再跳
- **登录方式**：桌面端支持扫码 / 密码登录；手机端用 App 内嵌的网易**官方登录页**登录，也支持粘贴 Cookie
- **进度可见**：验证 → 拉取任务 → 基础评分 → 额外评分，分段进度条 + 步骤 + 实时日志
- **失败可恢复**：单首失败自动跳过，整轮结束后自动补跑一次；失败原因分成 Cookie 失效 / 风控 / 网络 / 接口 / 未知，并给出下一步
- **不重复评分**：已评过的歌不会重复提交；请求超时也只查询确认一次，绝不重投
- **随时取消**：取消后立刻停止；没评到的歌记为「跳过」，不会谎报成「已提交」

### 记录与统计

- **今日曲目表**：今天评了哪几首、每首几分、批注写了什么
- **今天跑没跑**：今日页直接显示「今天还没跑 / 今天已跑 / 今天手动取消了 / 今天跑失败了」，
  成功时带上「今日已完成 N 首（基础 X 首、额外 Y 首），留下 M 条批注」和时间（两端一致）
- **执行情况**：完整执行历史按天合并，桌面端在今日页右栏、手机端在记录页
- **口味曲线**：你自己给 5 / 4 / 3 / 2 / 1 分各多少首；没有分数的历史曲目会单独说明
- **打卡格子图**：最近 53 周，绿 = 成功、红 = 失败、灰 = 没跑
- **今日导出**：把今天的曲目与批注导出成 Markdown（桌面端）
- **策略预演**：不提交、不改配置，先看四种评分策略分别会给出什么结果（桌面端）

### 批注（乐评文案）

- 提交评分时同时写一句批注，不再留空
- 批注由**本地模板**生成：不联网、不调用 AI、不需要填 key
- 三种语气（克制 / 热络 / 简短）× 三档长度（简短 / 标准 / 详细）
- 可选接入自己的 OpenAI 兼容接口；调用失败会自动回落到本地模板

### 自动化

- **定时执行**：每天固定时间自动跑；桌面端支持本地、云端或两者同时
- **错过补跑**：电脑开机晚了会检查「今天还没跑」并自动补一次（仅本地模式）
- **随机延迟**：避免每天都在同一秒发起请求
- **云端执行**：电脑关机也能跑，由 GitHub Actions 完成
- **通知**：邮件通知 + 应用内通知；手机端任务通知点击可直接回到 App

### 两端能力对照

| 能力 | 桌面端（Windows） | 手机端（Android） |
|---|:---:|:---:|
| 自动评分 / 额外任务补跑 | ✅ | ✅ |
| 扫码 / 密码登录 | ✅ | 网页登录 / Cookie |
| 定时执行 | 本地 + 云端 | 本地（系统闹钟） |
| 今日曲目表 / 执行情况 | ✅ | ✅ |
| 口味曲线 / 打卡格子图 | ✅ | ✅ |
| 批注（语气 / 长度） | ✅ | ✅ |
| 策略预演 / 今日导出 | ✅ | — |
| 邮件通知 | ✅ | — |
| 系统托盘 / 关闭行为 | ✅ | — |

## 下载与安装

安装包都在 [Releases](https://github.com/longyanbo1224-debug/ncmp_desktop/releases)。

### 桌面端（Windows）

1. 下载 `ncmp.desktop.zip`
2. 解压到任意文件夹（**不要只拿出 exe**，`_internal` 文件夹要一起保留）
3. 双击 `ncmp desktop.exe`

> 首次运行如果提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

### 手机端（Android）

1. 下载 `ncmp-mobile.apk`
2. 安装后打开 App
3. 点「网页登录」，在官方登录页完成登录，再点「我已登录，获取 Cookie」

> 如果手机上装过旧版且提示安装失败，先卸载旧版再安装。

## 三步开始

1. **登录**：桌面端在「账号」页扫码 / 密码登录；手机端走「网页登录」
2. **检查设置**：默认参数已经填好，一般不需要改；想调整评分策略或批注风格时再去「设置 / 任务参数」
3. **执行**：点「立即执行」（手机端是「开始评分」），看着进度跑完即可

跑完后：

- 「今日」页能看到今天评了哪些歌、每首几分
- 「记录」页能看到执行历史、口味曲线、最近评过的曲子

## 设置说明（桌面端）

| 页签 | 可以改什么 |
|---|---|
| 账号 | 手机号、密码（可一键转 MD5） |
| 任务 | 评分策略、等待时间、是否完成所有额外任务；批注开关 / 语气 / 长度 |
| 通知 | 收件邮箱、SMTP 授权码、服务器与端口、三个通知开关 |
| 自动化 | 定时执行、本地随机延迟、错过补跑、GitHub Actions 云端配置 |
| 通用 | 关闭按钮行为、打开日志文件夹 |

**评分策略**：按歌名 / 歌手名里是否含英文决定分数。

| 策略 | 含英文 | 不含英文 |
|---|---|---|
| 1–2 分 | 2 | 1 |
| 2–3 分 | 3 | 2 |
| 3–4 分（默认） | 4 | 3 |
| 固定 4 分 | 4 | 4 |

手机端在「任务参数」里调整同样的选项。

## 定时执行与云端执行（可选）

- **本地定时**：到点由本机执行。电脑需要开机，并且程序在运行。
- **错过补跑**：本地模式下，如果到点时电脑没开，启动后会补跑一次（仅当天、最多一次、有截止时间）。
- **云端定时**：由 GitHub Actions 执行，电脑关机也能跑。需要在设置里填仓库、workflow、分支和 GitHub Token，并按设置页的提示同步 workflow 与 Secrets。

如果你只需要「打开电脑时手动点一下」，可以完全不管这一节。

## 常见问题

### 扫码登录失败？

二维码 5 分钟过期，点「重新生成」即可。也可以改用密码登录；触发风控时程序会提示回到扫码。

### Cookie 过期了？

Cookie 大约 2 周过期。程序会在后台定时检查，失效时会通知并引导重新登录。

### 手机端登录提示「网络环境存在安全风险」？

请使用「网页登录」走官方登录页，不要用第三方接口直连。如果网页登录也异常，检查手机是否开着代理 / VPN。

### 手机端定时任务到点没执行？

手机定时依赖系统闹钟和前台服务，请确认：

1. 保存定时设置时允许「闹钟和提醒」权限
2. 系统设置里允许 App 自启动、省电策略设为「无限制」、允许通知
3. 在后台任务列表里锁定 App，避免被一键清理

### 今天任务没跑完怎么办？

- 电脑开机晚了：开启「错过补跑」，或手动点「立即执行」
- 想看失败原因：今日页会给出分类和下一步；详细过程在「运行详情」日志里
- 手机端：到「记录」页点开当天条目，能看到每次执行的结果

### 额外任务没跑满 15 首？

单首失败（资源异常、限流等）会被跳过，程序会自动补跑一轮。补跑后仍有剩余时，日志会写明还剩几首；常见原因是风控限流，建议把等待时间调大或换个时间再跑。

如果服务端提示「今日没有更多可评定歌曲」，说明今天能评的歌已经评完了，程序会按完成处理，不算失败。

### 口味曲线里的曲目数比「累计曲目」少？

说明有一部分曲目在服务端只标了「已提交」、没有返回具体分数（常见于在另一台设备上评过、或清理过本地记录之后）。这类曲目无法归入任何档位，曲线下方会单独写明「另有 N 首没有分数记录」。

### 退出登录 / 升级会丢配置吗？

不会。退出登录只清除登录态；评分策略、等待时间、定时设置都会保留。

### 数据存在哪里？

- 桌面端配置 / 任务历史 / 日志：`%LOCALAPPDATA%\ncmp desktop\`
- 桌面端评分账本等非敏感配置：`~\.ncmp_desktop\`
- 桌面端 Cookie / 密码等凭据：Windows 凭据管理器
- 手机端数据保存在 App 私有存储里，卸载 App 时一并清除
